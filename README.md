## Overview

Check Academic Results, Backlogs, Credits, Class Rankings, and Performance Analytics instantly without login.


What is actually in the repository: `backend/`, `frontend/`, `scripts/`. GitHub reports the primary language as TypeScript.

Published site recorded on the repository: https://malla-reddy-women-s-engineering-res.vercel.app

## Tech Stack

| Technology | Where it shows up |
|---|---|
| React | User interface |
| Vite | Frontend build tool |
| Firebase | Backend services used by this repository |
| Tailwind CSS | Styling |
| Recharts | Charts |

## Getting Started

```bash
git clone https://github.com/Bannysukumar/malla-reddy-women-s-engineering-results-website.git
cd malla-reddy-women-s-engineering-results-website
```

Scripts defined in package.json:

- `npm run dev` — `vite`
- `npm run build` — `tsc --noEmit && vite build`

## Deployment

- vercel.json is in the repository root.
- firebase.json is in the repository root.
- The repository homepage is https://malla-reddy-women-s-engineering-res.vercel.app.
